LEARNLOOP — 6-PAGE E-LEARNING WEBSITE

Pages:
1. index.html          Home, featured courses, login modal, contact form
2. courses.html        Course catalogue, search, level filter
3. course-details.html Course overview, learning outcomes, curriculum, progress
4. quiz.html           Multiple-choice quiz with countdown timer
5. results.html        Score, correct answers, answer explanations
6. leaderboard.html   Leaderboard and current learner points

How to run:
- Extract the ZIP.
- Open the folder in VS Code.
- Open index.html in a browser, or use the VS Code Live Server extension.
- No build tools or backend are required.

Features:
- Vanilla HTML, CSS and JavaScript.
- Six sample courses, each with a five-question quiz.
- Quiz timer (5 minutes), answer selection, score calculation and review.
- Course progress and leaderboard points saved with localStorage.
- Course search and level filtering.
- Demo login modal and contact form.

Important:
This is a front-end demonstration. Login and contact forms do not send data to a server.
localStorage is browser-specific; leaderboard scores are not shared between users/devices.
For a real deployment, add a secure backend, authentication, database and server-side validation.
